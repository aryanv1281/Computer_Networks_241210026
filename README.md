## Learning Outcomes

By completing these experiments, the student gains practical exposure to:

- Understanding basic computer networking components and their functions.
- Connecting computers and networking devices using suitable cables.
- Configuring routers and establishing communication between networks.
- Creating and testing peer-to-peer and LAN connections.
- Understanding IP addressing, subnet masks, and default gateways.
- Configuring DHCP and observing automatic IP address assignment.
- Verifying network connectivity and troubleshooting common issues.
- Designing and testing network topologies using Cisco Packet Tracer.

## How to Use This Repository

1. Open the folder or file corresponding to the required experiment.
2. Read the aim, theory, and implementation procedure.
3. Follow the topology and configuration steps where applicable.
4. Run the stated connectivity tests or simulation.
5. Review the observations, result, and conclusion.
